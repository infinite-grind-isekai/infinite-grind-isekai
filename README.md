## 실행 방법

**요구 사항**
- Java 17 이상
- Gradle (프로젝트에 Wrapper 포함)

```bash
# 빌드
./gradlew build

# 실행
./gradlew run
```

> Windows 환경에서는 `gradlew.bat build` / `gradlew.bat run` 사용

콘솔 출력이 깨지는 경우 JVM 옵션에 `-Dfile.encoding=UTF-8` 을 추가하세요.  
(IntelliJ: Run Configuration → VM options)

## 게임 흐름

```
타이틀 화면
  └─ 새 게임 시작
       ├─ 오프닝 스크립트
       ├─ 이름 입력 (3 ~ 8 글자)
       ├─ 직업 선택
       └─ 메인 메뉴 루프
            ├─ 1. 내 정보 보기
            ├─ 2. 인벤토리
            ├─ 3. 던전 입장
            │    ├─ 던전 선택
            │    ├─ 스테이지별 전투
            │    └─ 클리어 시 보상 획득
            └─ 0. 종료
```

## 던전 & 스테이지

| 던전 | 난이도 | 스테이지 | 구성 |
|------|--------|---------|------|
| 언노운 데이터 뱅크 | NORMAL | 1 | 자이언트 슬라임 (BOSS) |
| 테스트 서버 No.4 | NORMAL | 2 | 고블린 + 슬라임 → 고대 드래곤 (BOSS) |
| 디버깅 가든 | NIGHTMARE | 3 | 스켈레톤 × 2 + 고블린 → 오크 × 2 → 고대 드래곤 (BOSS) |

**난이도별 보상 배율**

| 난이도 | 배율 |
|--------|------|
| EASY | × 0.8 |
| NORMAL | × 1.0 |
| HARD | × 1.3 |
| NIGHTMARE | × 1.6 |

- 마지막 스테이지는 반드시 보스 몬스터 1마리로 구성됩니다.
- 패배 시 던전이 초기화되고 체력이 전량 회복됩니다.

## 전투 시스템

### 턴 구조

```
플레이어 스킬 선택
  └─ 데미지 계산 & 적용
몬스터 자동 스킬 선택 (랜덤)
  └─ 데미지 계산 & 적용
```

플레이어 턴 후 몬스터들의 턴이 자동으로 연속 실행됩니다.

### 데미지 공식

```
데미지 = max(1, 공격자 ATK + 스킬 데미지 - 방어자 DEF)
```

### MP 회복

- 매 턴 시작 시 전 참여자(플레이어 + 몬스터) **MP +10** 자동 회복
- 최댓값을 초과하지 않습니다

### 스킬 사용 불가 시

사용 가능한 스킬이 없으면 플레이어 턴이 자동 스킵되고 몬스터들만 행동합니다.

### 전투 종료 조건

| 조건 | 결과 |
|------|------|
| 스테이지 내 모든 몬스터 사망 | 스테이지 클리어 → 다음 스테이지 진입 |
| 마지막 스테이지 클리어 | 던전 정복 완료 + 보상 획득 |
| 플레이어 HP = 0 | 패배 → 던전 초기화, 체력 전량 회복 |

## 경험치 & 레벨업

### 다음 레벨 필요 EXP

```
필요 EXP = 현재 레벨 × 100
```

| 레벨 구간 | 필요 EXP |
|-----------|---------|
| 1 → 2 | 100 |
| 2 → 3 | 200 |
| 3 → 4 | 300 |
| N → N+1 | N × 100 |

### 레벨업 효과

- ATK **+5**, DEF **+2**, HP **+10**, MP **+5**
- 레벨업 시 HP +10, MP +5 즉시 회복 (최댓값 초과 불가)
- 한 번에 여러 레벨업도 가능합니다

## 보상 시스템

- 몬스터를 처치할 때마다 Gold와 아이템이 `RewardContext` 에 누적됩니다
- 던전 완전 클리어 시 누적 보상 전체를 캐릭터가 획득합니다
- 패배 시 누적 보상은 소멸합니다

## 프로젝트 구조

```
src/main/java/org/rpg/isekai/
│
├── Application.java                  # 진입점
│
├── controller/                       # 게임 로직 컨트롤러
│   ├── GameController.java           # 게임 루프 (Starter 구현체)
│   ├── DungeonManager.java           # 던전 객체 생성 & 보관
│   ├── MonsterManager.java           # 몬스터 팩토리 레지스트리
│   ├── IoCManager.java               # 의존성 초기화 & 주입
│   └── ...
│
├── domain/
│   ├── battle/                       # 전투 핵심 도메인
│   │   ├── Battle.java               # 턴 실행 엔진
│   │   ├── Dungeon.java              # 던전 (스테이지 묶음 + 리워드 컨텍스트)
│   │   ├── BattleStage.java          # 스테이지 (몬스터 집합 + 전투)
│   │   ├── StageContext.java         # 배틀 내부 상태 (히스토리, MP 회복)
│   │   ├── StageBlueprint.java       # 스테이지 구성 청사진 (몬스터 팩토리)
│   │   ├── RewardContext.java        # 던전 내 보상 누적기
│   │   └── BattleTurn.java           # 턴 결과 레코드
│   │
│   ├── character/                    # 플레이어 캐릭터
│   │   ├── Character.java            # 캐릭터 (EXP, 레벨업, 스탯 계산 포함)
│   │   ├── Stat.java
│   │   └── Inventory.java
│   │
│   ├── job/                          # 직업 (Warrior, Mage, Archer, Gunslinger)
│   ├── monster/                      # 몬스터 (Slime, Skeleton, Goblin, Orc, AncientDragon, GiantSlime)
│   ├── skill/                        # 스킬 (ActiveSkill, PassiveSkill + 구현체)
│   └── item/                         # 아이템 (Weapon, Armor, Potion, Material)
│
├── ioc/                              # IoC 컨테이너
│   ├── Container.java                # 싱글턴 컴포넌트 저장소
│   └── Starter.java                  # 게임 시작 인터페이스
│
└── view/                             # 콘솔 UI
    ├── TitleView.java                # 타이틀 & 오프닝
    ├── CharacterSetupView.java       # 이름 입력 & 직업 선택
    ├── GameMenuView.java             # 인게임 메인 메뉴 & 정보 화면
    ├── DungeonBattleView.java        # 전투 화면 (아스키 아트 포함)
    └── ConsoleUtils.java             # 화면 클리어, 타자기 효과, 딜레이
```

### 아키텍처 요약

```
Application.main()
  └─ IoCManager.run()
       ├─ MonsterManager.prepare()    # 몬스터 팩토리 등록
       ├─ DungeonManager.prepare()    # 던전 객체 조립 (BluePrint 기반)
       └─ Container.register(Starter, GameController)

Container.get(Starter).start()
  └─ GameController.start()          # 게임 루프 진입
```
